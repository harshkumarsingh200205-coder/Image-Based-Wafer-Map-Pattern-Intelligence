# Changelog

All notable changes to the Image-Based Wafer Map Pattern Intelligence project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-09-06
### Added
- Initial project scaffolding and master template architecture.
- Complete system specification (`PROJECT_SPEC.md`), requirements (`REQUIREMENTS.md`), and architecture design (`ARCHITECTURE.md`).
- Master configuration in `configs/config.yaml` and dependencies in `requirements.txt`.
- Skeletons and interface contracts for Preprocessing, Segmentation, Spatial Features, Predictive Modeling, Explainability, Evaluation, and Streamlit Dashboard.
- Unit test suite foundations in `tests/`.
